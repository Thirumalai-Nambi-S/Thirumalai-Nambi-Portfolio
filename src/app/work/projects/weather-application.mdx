## Overview

A clean, fast weather web app that lets anyone search a city and immediately see current conditions, an hourly outlook, and a multi-day forecast — plus an interactive map centered on the searched location for geographic context.

## Problem Statement

Most quick weather lookups mean opening a heavy app or wading through ad-filled sites just to see the temperature and a forecast. This project strips that down to a single fast page: search, see the numbers, see the map, done.

## Key Features

- **Live Search** — Type any city or place name and get matched coordinates and current conditions within seconds.
- **Hourly & Multi-Day Forecast** — A scrollable hourly breakdown alongside a several-day outlook, so short-term and longer-term planning are both covered in one view.
- **Interactive Map** — A Leaflet-based map recenters and drops a marker on the searched location, giving instant geographic context alongside the numbers.
- **Responsive Layout** — Built mobile-first so the same experience holds up from a phone browser to a widescreen monitor.
- **Deployed at the Edge** — Hosted on Cloudflare Pages for fast global load times with no backend server to maintain.

## Technologies Used

- **JavaScript** for the search flow, data fetching, and UI state
- **A public weather REST API** for current conditions and forecast data
- **Leaflet** for the interactive map and location marker
- **HTML/CSS** for a lightweight, dependency-light front end
- **Cloudflare Pages** for deployment
