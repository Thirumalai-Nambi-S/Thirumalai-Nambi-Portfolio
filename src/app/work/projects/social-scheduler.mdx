## Overview

Social Scheduler is a web app for planning social media content ahead of time. Instead of posting in the moment, users draft content, assign it a publish date and time, and manage everything from a single queue.

## Problem Statement

Consistent posting is one of the hardest parts of running a social presence — it's easy to plan content but hard to remember to actually publish it at the right time. This project turns "remember to post" into "schedule it once," reducing missed windows and last-minute scrambling.

## Key Features

- **Post Drafting** — Compose posts with captions and scheduling details in a focused editor.
- **Scheduling Queue** — Assign a date and time to each post and see everything that's upcoming in one organized queue.
- **Calendar-Style Overview** — Visualize what's scheduled and when, making gaps or overlaps in the content plan easy to spot.
- **Status Tracking** — Posts move through clear states (drafted, scheduled, published) so it's always obvious what's pending.
- **Responsive UI** — Works comfortably from both desktop and mobile for planning on the go.

## Technologies Used

- **Next.js & TypeScript** for the application shell and type-safe routing
- **React** for the scheduling UI and interactive components
- **Tailwind CSS** for fast, consistent styling
- **Vercel** for deployment and hosting
